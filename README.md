# Minecraft 禮品卡十元硬幣刮刮樂 ⛏️🪙

一個使用 **HTML5 + CSS3 + p5.js** 製作的單頁式互動網頁。
讓使用者可以模擬手持「新台幣十元硬幣」，刮開「Minecraft 禮品卡未開封」的銀色封條，最後揭曉「Minecraft 禮品卡已開封」的兌換序號！

## 🌟 互動特色

- **擬真十元硬幣跟隨**：3D 立體微斜視角的新台幣十元硬幣，接觸點精確跟隨手指觸控或滑鼠移動，刮拭時帶有物理阻力震顫反饋。
- **雙圖層虛擬封條**：封條底層精確對齊已開封卡片的序號（`473Q7-GRCF2-W6WKG-R3GXT-X3VXZ`），上方覆蓋未開封銀漆圖層。
- **刮除物理粒子**：刮動時噴濺金屬粉屑微粒，刮開完成時噴發慶祝彩帶。
- **原生音效反饋**：Web Audio API 即時合成金屬刮拭摩擦聲與成功和弦音效。
- **跨平台支援**：完美適配桌機滑鼠與行動裝置觸控，支援一鍵複製兌換代碼。

## 🎮 體驗方式

刮除封條面積達到 **80%** 以上時，系統將自動完成剩餘刮除並呈現完整已開封卡片！

## 🛠️ 技術棧

- **p5.js** (1.9.4)
- **Web Audio API**
- **HTML5 Canvas & Responsive CSS**
